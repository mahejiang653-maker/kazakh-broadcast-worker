# Дәулет V45：提高音调时保护男声主体

基线：`2475cc5651c89c294c6849479cb9ffec091d8e0d`，实际线上 V44。
此次反馈的触发条件是用户提高“音调”，而非默认值下的一般音色变化。

## 可复现的处理链因素

V44 的慢脉冲 bell Q=3.2，第三谐波 bell Q=2.5。相邻脉冲证据不足时，
控制器退回 bell 处理分支；该分支的慢脉冲和第三谐波削减较大，两个 bell
的影响范围仍延伸到正常男声的第二/主体谐波。130Hz 单点验证漏掉了
140/150Hz 附近更明显的主体衰减，升调后这一区间更值得保护。

分别绕过各处理分支的控制实验表明，140Hz 的主体变化从 -0.677dB 在绕过
慢脉冲 bell 时变成 -0.272dB，在绕过第三谐波 bell 时变成 -0.396dB；
绕过共振或相邻脉冲分支不能解释该变化。诊断绕过只在测试脚本中使用。
这证明了一项 DSP 因素，不证明用户未提供的具体录音只有这一项原因。

## 最小修正

- 慢脉冲 bell Q 从 3.2 改为 6；第三谐波 bell Q 从 2.5 改为 5。
  两条处理范围同时收窄，保留中心跟踪、中心削减预算、门限和跨块状态。
- 新闻/缓存版本改为 `daulet-v45-raised-pitch-stable`。
- 原来的 130Hz 主体稳定检查扩展到 110/120/130/140/150/160Hz，覆盖不同
  处理分支；保留实际启用去脉冲且足够削减的断言。增加升调值在不同新闻
  方向语段中一致、每块仍为单个 prosody 的检查。

Edge voice、rate/pitch/volume 算法、文字、编号停顿、分句和拼接不改动。
标准新闻 UI 音调 0/+5/+10/+15 对应无手动情绪时基准 SSML pitch
+0.82/+5.82/+10.82/+15.82%，各块自动 pitchDelta 仍为 0。用户主动情绪
方向已有的极小偏移和原有上下限保留。未引入变声、后期移调、新滤波器、
神经模型或付费服务。

## 验证

同样的男声主体成分持续存在，交替加入慢脉冲后，比较每秒后半段的主体幅度：

| 主体 Hz | V44 变化 dB | V45 变化 dB |
|---|---:|---:|
| 110 | 0.488 | 0.133 |
| 120 | 0.164 | 0.041 |
| 130 | 0.160 | 0.037 |
| 140 | 0.677 | 0.193 |
| 150 | 0.565 | 0.164 |
| 160 | 0.165 | 0.046 |

控制器检测帧数及中心削减预算相同；不是通过禁用去脉冲来通过检查。
原有 52/68/82Hz 慢基频实际衰减、普通男声/无声辅音保护等检查也通过。

另外在实际 V44 Worker 上，以同一三段虚构哈萨克语测试稿新生成
0/+5/+10/+15 四档音调，每档三个 PCM 块。每份原始 PCM 分别走 V44/V45
处理和相同 MP3 编码，每版共 186.52 秒；四档各自的时长、拼接与控制器
指标一致，前后 MP3 LUFS 最大相差 0.01，真实峰值最高约 -2.43dBTP。
在选定的稳定强慢脉冲窗口中，正常第二谐波相对旧版恢复约 0.10–0.18dB；
第一谐波也恢复约 0.17–0.51dB。这是窄滤波保留更多邻近能量的取舍，不能
称为进一步消除了所有气泡音。

本地生产构建及全部 34 项回归、严格 TypeScript 检查通过。移除注释后，
真实 PCM 对照所用 DSP 与生产代码编译结果一致。三轮交错预热的纯 DSP
测试：186.52 秒音频的中位耗时 V44 1.58 秒、V45 1.78 秒；不含网络、读盘
和编码，存在调度波动。滤波器数量不增加，但不将这组数据宣称为提速或
耗时完全不变。线上部署、提高音调后的播放结果另存于交付报告。

## 限制

没有人工盲听评分。实际音频和信号对照支持保护主体谐波的改动，不等于
全部“粗细变化”已经消失。Edge 模型自身的声区、元音共振和句子起音
仍可能随升调变化。本次不强行统一它们，以免改变 Дәулет 身份和声线。
