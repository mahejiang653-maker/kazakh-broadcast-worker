# Дәулет v3.7：DeepFilterNet 0.5.6 实验与局部喉音处理

本轮沿用 `kk-KZ-DauletNeural`、新闻文本规则、320 ms 编号停顿、PCM 流和单次 MP3 编码。只更新 Дәулет 新闻 DSP、缓存版本和相关回归检查。

## 官方模型实测

锁定官方 [v0.5.6](https://github.com/Rikorose/DeepFilterNet/releases/tag/v0.5.6)，源码提交 `978576aa8400552a4ce9730838c635aa30db5e61`。0.5.6 是软件版本；测试使用该版本仓库中的 `DeepFilterNet3_onnx.tar.gz`，SHA-256 为 `c94d91f70911001c946e0fabb4aa9adc37045f45a03b56008cb0c8244cb63616`。

阅读了 `libDF/src/bin/enhance_wav.rs`、`tract.rs`、`lib.rs` 和 Python `df/enhance.py`、`deepfilternet3.py`。其核心是听觉频带增益和多帧复数滤波；阶段由模型估计的局部信噪比控制，可回混原声限制衰减。它的训练任务是语音降噪。

用官方 Linux 二进制，在三段真实 Edge 配音上分别运行默认全量增强和 `-a 3` 受限增强，未启用 post-filter。输入来自同一批 v3.6 PCM，24→48 kHz，尾部补 200 ms，`-D` 补偿延迟，再转回 24 kHz 并按原始长度裁齐。每段单独启动，避免跨文件模型状态干扰。

```sh
deep-filter-0.5.6 -m DeepFilterNet3_onnx.tar.gz -D -v -o full padded-48k.wav
deep-filter-0.5.6 -m DeepFilterNet3_onnx.tar.gz -D -v -a 3 -o limited padded-48k.wav
```

三段素材为 9.400 / 33.970 / 49.195 秒的短句、国际新闻语体、数字日期长句。B/C 为虚构测试稿。默认模型与输入的波形相关系数约 0.99984–0.99994。固定低脉冲候选中的 55–100 Hz，相对 450–4000 Hz 语音主体仅额外降低约 0.1–0.2 dB；受限模型更弱。原生推理约用音频时长的 6–8%，包括加载的进程耗时约 8%。在这些干净 TTS 素材上，模型基本保留了发声纹理，整段降噪的针对性不足。

## 实际采用的处理

默认链路采用研究后的独立轻量 DSP，实现多帧上下文、分支门控和有上限的局部衰减；官方神经模型用于 A/B 参照。网站无新增运行时依赖。

- 80 ms 检测窗、20 ms hop，以窗口中心定位；相邻三帧取中值，单个相关峰不直接控制输出。已取得的 PCM 提供 60 ms 前视，不增加 Edge 请求或网络等待。
- 保留第一可信周期的选择，防止把正常 100–160 Hz 男声误判为倍周期。较弱周期性候选也参与多帧确认。检测是启发式低脉冲判断，未经真人气泡音标注。
- 85 Hz / Q 1.1 支路仅由确认后的低周期候选驱动，控制上限 4.2 dB，20 ms attack / 100 ms release。
- 新增 245 Hz / Q 2.0 泛音支路，需同时满足低脉冲确认与局部能量占比。控制上限 1.2 dB，35 ms attack / 100 ms release；孤立支路中心至少保留约 87% 原声振幅。
- 既有 145 / 285 / 410 Hz 共振控制仍共用 3 dB 上限。所有五支路的控制量总和不超过 6 dB；这是控制预算，不能当作复合频响或全频最低增益。
- 全文响度、峰值余量、句尾保留、接缝静音与一次性 MP3 编码保持。所有滤波器和分析状态跨 chunk 连续。
- 每个 chunk 到达即分析、处理，可与下一段 Edge 生成重叠；额外时间轴仅覆盖当前 chunk，不复制整篇波形。

同源 PCM 对比 v3.6，新版在固定候选片段中的 55–100 Hz 能量进一步减少约 0.7–1.0 dB，180–320 Hz 泛音约减少 0.2–0.6 dB。正常低音与中高频整体变化很小，响度差约 0.01 LU。两段编号后实测安静区仍为 360 / 350 ms，chunk 接缝仍为 280 / 420 ms，长度逐样本一致，无 PCM 削波。

这些指标表示局部频段变化，不能换算成“真人感”或“气泡音消除率”。Edge 原始声线的发声纹理无法用轻量 DSP 完全重建；保留同一位播音员的声音也限制了可接受的处理强度。交付试听包括旧版、新版和官方模型参照，供实际听感判断。

## 验证与回滚

生产构建与 18 项检查通过：哈萨克字符、专名数字、完整语义分块、13 个编号停顿、正常男声周期保护、低幅句尾、无声辅音型噪声保护、限幅预算及流式传输失败处理。三段真实音频另行检查频谱、响度、真峰值、波形长度和停顿。42 chunk / 1008 秒真实语音回放用于 CPU 计时；它是 DSP 性能测试，并非 42 次线上合成。

缓存版本为 `daulet-news-v3.7`，避免命中旧版声音。回滚应同时还原 `daulet-dsp.ts` 和版本号，保持代码与缓存版本对应。
