# Дәулет v3.10：交替低脉冲的局部平滑

本轮接续 v3.9，继续使用免费 `kk-KZ-DauletNeural`。新增轻量的低频相邻脉冲处理，并相应减少原来的跟踪 EQ 强度。没有新增运行时依赖或神经模型。它针对部分可测量的交替脉冲，不是彻底消除喉音或实现真人发声的声明。

## 1. 定位：剩余的机械感与气泡纹理

v3.9 已让紧凑新闻条目保持同一个 Edge 上下文，并修复手动情绪路径的过多 prosody 区块。本轮保留这些行为。剩余的语义重音、音节发声和句尾发声纹理，仍受到 Edge 原模型影响；DSP 不能补出理解新闻内容的能力。

实际未编码 Edge PCM 中，部分约 60–70 Hz 片段同时出现更强的约 120–140 Hz 主体成分，以及约 180–210 / 300–350 Hz 的奇数泛音。这与交替脉冲／周期倍增的声学表现相符。只是声学推断，不证明 Edge 模型内部机制，也不代表所有低音或喉音都是同一种现象。这些成分在 MP3 编码前已经存在，不能单归因于压缩。

旧版 DSP 重点处理慢脉冲基频与第三泛音，较高的奇数泛音及交替纹理仍可保留。继续增加广泛的低频削减，容易削薄成熟男声。因此本轮增加局部脉冲平滑，保留普通男声的主体成分。

## 2. 修改文件

- `app/lib/daulet-dsp.ts`：增加交替脉冲证据、多帧频率一致性检查、低频相邻脉冲支路和指标；它与旧 EQ 共用处理预算。
- `app/lib/daulet-news.ts`：只将缓存／响应版本改为 `daulet-news-v3.10`。

- `docs/daulet-adjacent-pulse-v310.md`：本记录。

## 3. Edge 参数和文本规则

默认新闻 UI 1.00×、pitch/volume 为 0 时：rate `1.01303`，SSML 为 `+1.30%`；pitch `+0.82%`；volume `+0.00%`。原有很小的语义密度／条目方向增量继续生效。本轮不靠进一步提高音高或速度制造改善。

文本预处理与 v3.9 相同：完整哈萨克字符、数字日期／装备名称、专名保护和完整语义分块继续使用。普通 1–3 句一块；紧凑编号条目可保留 4–5 句，但须同时不超过 90 词／650 字符。阈值只决定是否合并完整单位，不截断词或名称。`Бірінші.` 等 13 个编号的显式 320 ms 停顿、原生 `<p>/<s>`、每请求一个外层 prosody 均保留。0.95× / 1.05× 保留。

## 4. 新 DSP 支路

分析继续使用 80 ms 窗、20 ms hop、1.5 kHz 分析采样率和原有 PCM 中的 60 ms 前视；音频始终为 24 kHz。

交替支路要求慢周期低于 92 Hz，低脉冲分数超过 0.20，并同时满足：

- 半周期相关性大于 0.10；全周期相关性比它高出 0.12。
- 第二泛音功率大于第一泛音的 1.15 倍；第一泛音又须超过第二泛音的 2.5%，避免只有谱泄漏。
- 三帧中值确认，至少两帧有证据；这些帧的频率最大／最小比不超过 1.12。跳变时关闭新支路。

这些是保守启发式规则，没有真人气泡音标签或 EGG 数据，不能当作经验证的哈萨克语 creak 分类器。

对于确认片段，使用 420 Hz 一阶低通取得低频权重成分 `L`。短环形历史提供半个慢周期的相邻脉冲（约 5.4–11.1 ms），分数延迟线性插值。输出为 `y[n] = x[n] + m × (L[n-D] - L[n])`，`m` 上限为 0.20，仍使用 4 ms attack / 55 ms release。稳定周期下，奇数慢周期泛音在半周期处反相，偶数主体泛音同相，因此可以局部减轻奇数纹理。低通是柔和权重，并非高频完全不受影响；实际变化见下表。

没有对完整语音做延迟、时长拉伸、整体移调或重合成。支路只混合有限低频权重的历史样本，全部状态跨 chunk 保留。为避免叠加重削低音，以 `-20 log10(1-2m)` 保守预留支路预算，并降低旧基频／第三泛音 EQ 目标。共振预算仍为 3 dB，总控制预算仍为 13 dB；这不是复合滤波器实际频响的上限声明。

原有 55 Hz 高通、210 Hz / Q 0.8 / -0.6 dB、条件共振处理、一次全文响度增益继续使用。没有新增压缩、降噪、噪声门、混响、echo、AutoTune 或假呼吸声。

生产构建和 25 项回归通过；两个修改的 TypeScript helper 严格检查无诊断。包括变化的正常男声、普通低音、奇数泛音与高频保留、十三个编号、UTF-8、日期数字、chunk 顺序、失败／取消处理和现有页面／地球包。

## 7. 仍然存在的限制与回滚

Edge 原模型的音节发声、喉部共振、不规则声带脉冲、句尾拖低和语义重音，不能用有限 DSP 全部重建。新支路只覆盖有证据的交替周期，不处理所有粗糙纹理；强行扩大范围可能使声音空、薄或出现电子感。普通低音仍是合法声音特征，不能一概去掉。
