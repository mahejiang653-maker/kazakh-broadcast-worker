# 全球日报—V52地球仪—图片检索：统一 DATA LOCK v1

文件格式使用既有 V52 导入对象 `{"meta":{...},"news":[...]}`，**不是**另起字段结构。

- `meta.schemaVersion` 固定 `news-data-lock/v1`，`meta.edition` 固定 `daily-10`，`meta.date` 为北京时间截止日期，`meta.timeZone` 固定 `Asia/Shanghai`。
- `meta.windowStart` 为前一天 `13:00:00+08:00`（含），`meta.windowEnd` 为当天 `13:00:00+08:00`（不含）。`meta.dataLock` 为日报唯一编号。`newsCount=10`、`imagesPerNews=3`。
- 新闻数组**严格Top1至Top10**。保留已在地球仪生产引擎使用的 `id`、`title`、`summary`、`location`、`focusLabel`、`lon`、`lat`、`countryIso3`、`sceneMode`、`scenePlan.primaryIso3`。新增 `eventType`、`placeType`、`relatedCountryIso3s`、`sources:[{name}]`、`reportedAt`、`articleUrls`。
- `reportedAt` 首选带 `+08:00` 的实际发布日期；仅能确定日期时写 `YYYY-MM-DD`，显示核验警告而**不编造时分秒**。具体事实发生时间可另外保留在 `occurredAt`。
- `articleUrls` 每条最多3个**报道网页** HTTPS 链接，必须实际确认；未核实则空数组（会提示缺口）。**不是**图片 URL。图片网站的审核结果另存在其 `results[].imageUrl`。
## Top1–Top10：全球权威媒体多元信源规则（2026-10-12补充）

**此规则适用于第一板块10条新闻的初次选题、事实核对、哈萨克语稿及后续全部七大板块，不仅限第六板块的30个链接。**

1. **搜索范围必须覆盖全球主要可信、可追溯的新闻采编机构，不得长期只从两三家媒体提取10条新闻。** 国际主要媒体示例：Reuters（路透）、AP（美联社）、AFP（法新社）、BBC、CNN、Al Jazeera（半岛电视台）、RIA Novosti（俄新社）等；中国的重要信源包括新华社、央视、人民日报、中国日报、政府及部委发布；新疆两条优先核对新疆日报、天山网、新华社新疆分社和相关权威发布。上述为**优先覆盖池，不是唯一白名单**；其他可信国际、地区媒体和真正一手机构报告也可采纳。
2. **整期10条的来源分布必须体现多样性。** 编辑验收目标是：10条新闻的**首要报道媒体至少来自6家不同的独立采编机构**；原则上任何单一媒体不得成为超过3条新闻的首要报道媒体。新闻价值、最新时效和真实可核验性优先于凑数，遇到不足时要继续扩大查证而不是伪造媒体来源或擅自更换高价值新闻。
3. **对重大军事、安全与争议事实进行交叉核实。** 尽可能取得至少两条来源独立、身份明确的核验依据；区分一方军方或政府“声称”、记者独立核实的事实及另一方回应。各国官方、联合国和国防部资料可作为强有力的一手证据，但不能只因十条事件都有政府声明就把这些机构冒充成“不同新闻媒体”达成媒体多样性指标。
4. **按实际采编主体计算不同媒体，不以URL和转载网页数计算。** 同一通讯社稿件被不同网站原样转载，新闻事实的一手报道来源仍是同一家通讯社；同媒体不同语言、地区版、子域名不能重复计数。不同媒体存在不同立场时应客观交叉验证，不因某家机构名称响亮就省略证据。
5. **不牺牲前述内容与地理标准。** Top1–Top8仍从当天全国及全球真正重要的进展中选择，Top9–Top10仍为新疆新闻；搜索窗口、DATA LOCK顺序、事件坐标和新闻事实一致。不得为了来源数量人为制造某地区新闻，也不得拿窗口外旧报道充当天内新进展。
6. **在既有JSON记录真实来源。** 使用现有每条 `news[i].sources:[{name}]` 保存编辑可核查的原始来源，第一项记首要报道媒体；其他项记独立佐证与重要官方出处。不得用不存在的来源名称填满数组。如未满足全局媒体多元验收，应报告实际缺口，不宣称多元性已达标。

**第六板块仍额外执行**“每条新闻3家不同媒体机构、各报道网页实际有相关新闻图片”的独立硬性要求。整期10条“至少6家首要报道媒体”与第六板块逐条“三家不同媒体”的统计口径不同，必须同时符合。

媒体是否有独立采编主体、转载是否独立调查以及事实是否准确，无法由简单JSON结构检测可靠完成；应在原有每日新闻搜索与来源核验中完成，不新增每日Work、收费AI调用或额外搜索作业。

## 第六板块：新闻报道网页硬性验收（2026-10-12新增）

**目标仍为10条新闻 × 每条3个网页 = 30个已核实新闻报道网页链接。以下两项缺一不可：**

1. **报道网页内必须有与该条新闻直接相关的实际新闻图片**。逐页打开确认至少有一张可正常显示、能辨认且确实对应新闻事实的图片；不能用站点Logo、广告、纯文字、无关配图、通用站点OG占位图或只有视频播放器/视频封面的页面充数。链接仍指向**包含图片的新闻报道网页**，不是图片文件或图片搜索结果页。
2. **同一条新闻的三个网址分别来自三家不同媒体机构**。检查媒体名称与实际出版/编辑主体，不只按域名判断；同一媒体的不同页面、子域名、地区版或同集团同编辑主体不能充当不同媒体。优先选择彼此独立、真实发布报道的来源，并避免重复转载同一稿件充数。
3. 网页必须确实打开且无需登录/订阅才能看到相关图片与报道；网址不得404、403、跳视频专页、无关报道或过时旧稿冒充新进展。需要核对该新闻对应的标题、事实和统计窗口。
4. 如果某条新闻暂时不足三家均含相关真实图片的媒体网页，该条标记**不完整**并继续补搜，不得用无图页或同媒体不同URL硬凑。不能在未实测页面图片存在时标记 `3/3`，也不能对30条链接宣称全部达标。
5. `news[i].articleUrls` 只存经过上述人工/网页核验的报道URL；为零到三条的接口容错并不代表第六板块可以少于三条即算完成。审核通过的图片直链应仅存在图片网站的 `results[].imageUrl`；这些直链不替代第六板块网页。

静态纯JavaScript的链接域名/字符串检查不足以证明图片加载和媒体机构独立性。日常第六板块应在原本找报道的过程中核实，不要另起每天自动收费AI验图、真实图片搜索或Work任务。

- 地球仪：打开当前 V52·A1 R6 页面 → 设置 → 导入统一10条DATA LOCK JSON文件 → 检查提示 → 保存并应用 → 地球仪按Top1–Top10显示。旧13条源文件保留为历史预览。
- 图片网站：打开原站 → 导入**同一个**JSON文件 → 自动填充十个标题 → 开始检索；后端再次检查字段、顺序、地点和时间后创建原有10×3任务。旧手动输入和历史任务均保留。
- 日报：只生成一次同一份JSON，七大板块引用相同 `id/title` 和 `meta.dataLock`；并将新闻报道链接填入对应 `news[i].articleUrls`。无需每日修改代码。

验证采用纯JavaScript，不调用Gemini，也不启动真实图片任务。仅做基本的共同事件词与国家/城市标签错误检测；跨语言事实核验、真实地理归属和报道网址是否可打开仍需新闻编辑核验。
