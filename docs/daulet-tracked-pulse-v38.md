# Дәулет v3.8：跟踪低脉冲，保留主体男声

用户反馈 v3.7 的气泡音、喉音和咕噜感仍重。本轮只改 Дәулет 新闻 DSP、缓存版本、相关检查和本文档；继续使用免费 `kk-KZ-DauletNeural`，没有新增模型、付费 API 或运行时依赖。

## 定位与取舍

复用三组真实 Edge 输出：短句 A 9.400 秒、国际新闻语体 B 33.970 秒、数字日期长句 C 49.195 秒。B/C 是虚构测试稿。同一份未编码 PCM 分别通过 v3.7 和 v3.8，排除重新合成的差异。

部分候选的频谱同时包含约 65 / 130 / 195 / 260 Hz 的成分，其中 130 Hz 强于 65 Hz。这与周期倍增/交替脉冲相符；不是对 Edge 模型内部机理的证明，也不代表每个低音都是气泡音。v3.7 固定 85 Hz 的并行减法偏离部分实际低脉冲频率，且 20 ms attack 和固定泛音处理对短促片段不足。此前官方 DeepFilterNet 0.5.6 实验基本保留这类干净语音纹理，见前一份实验记录。

本轮先测试温和的跟踪 EQ，但固定候选额外衰减仍只有约 0.5–1 dB；未采用该候选。最终对证据明确的片段加强局部处理，对弱证据减少处理。目标是减轻低脉冲重量，保留相邻的主体男声频率；不通过整篇低频削减、提亮或提高响度制造改善。

## 实际实现

- 继续用 80 ms 窗、20 ms hop、两级 400 Hz 低通和 1.5 kHz 分析。音频保持 24 kHz。三帧中值确认和现有 PCM 内的 60 ms 前视沿用，不增加网络等待。
- 对相关峰做抛物线插值，降低离散 lag 引起的频率跳动；时间轴同时携带证据强度和频率。
- 普通男声仍选首个可信周期。较弱的交替脉冲必须同时满足倍周期相关峰优势和 Hann 窗 Goertzel 半频能量证据，避免仅凭倍周期相关峰误判正常男声。这是启发式检测，没有真人气泡音标注。
- 主支路改为跟随检测频率的串联 bell EQ，Q 1.6，上限 8.5 dB。强度为 `clamp((confidence-0.20)/0.60,0,1)`；弱证据低于 0.20 不激活。较强处理仅覆盖短促的确认片段。
- 泛音 bell 改为跟随三倍低脉冲频率，Q 2.5，上限 1.5 dB。在约 65 Hz 的候选中轻处理约 195 Hz，保留较强的约 130 / 260 Hz 主体成分。
- attack / release 为 4 / 55 ms，频率平滑 5 ms。滤波系数每 10 ms 刷新并在 10 ms 内渐变，所有状态跨 chunk 保持。系数采用标准 RBJ peaking EQ；不是 pitch shifting 或声带重合成。
- 保留 55 Hz 高通、210 Hz / Q 0.8 / -0.6 dB 和 145 / 285 / 410 Hz 的既有共振处理（仍共用 3 dB 预算）。五个控制量总和上限 13 dB，是控制预算，不能解释成全频段衰减或实际复合频响。
- 全文一次响度增益仍目标 -22 LUFS、增益 -3 至 +2 dB、样本峰值余量 -2 dB。继续单次 160 kbps MP3 编码；没有新增压缩、噪声门、混响、呼吸声或重降噪。

## A/B 实测

候选掩码固定来自旧版 v3.7 的三帧中值：普通候选分数 >0.25，较强候选 >0.70。没有根据新版输出挑选有利片段。频段统计采用离线零相位 Butterworth 滤波（2 阶、前后向），避免分析滤波器的群延迟把前一片段能量算到当前片段；它只用于测量，不进入网站运行路径。数值是新版相对 v3.7 的能量变化。

| 样稿 | 全部候选时长 | 较强候选时长 | 候选 45–100 Hz | 较强候选 45–100 Hz | 较强候选 100–180 Hz | 较强候选 500–4000 Hz |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 0.74 s | 0.44 s | -2.81 dB | -4.94 dB | -0.14 dB | -0.05 dB |
| B | 1.88 s | 0.38 s | -0.83 dB | -4.07 dB | -0.27 dB | -0.04 dB |
| C | 3.20 s | 1.00 s | -0.97 dB | -4.05 dB | -0.14 dB | -0.03 dB |

较弱候选仍有较小改善，不能把较强片段的 4–5 dB 宣称为整篇效果。旧检测中可信 105–160 Hz 的正常片段，全频 RMS 变化约 -0.006 / -0.005 / +0.017 dB。MP3 新旧响度最大差约 0.04 LU；新版 A/B/C 真峰值为 -4.39 / -3.71 / -2.43 dBTP。无 PCM 削波，逐样本长度相同。

音频 A/B 包括三组完整 MP3 和几个固定候选附近的短片段，使用相同编码参数并内嵌于离线 HTML。已生成真实音频并检查波形、频谱、响度和停顿；没有把客观测量冒充人工盲听结论。指标不能换算成气泡音消除率或真人感评分，最终听感需用试听核对。

## 保留的稳定行为

- Edge 标准新闻参数沿用：界面 1.00×、pitch/volume 0 时，rate `1.01303`（SSML `+1.30%`）、pitch `+0.82%`、volume `+0.00%`；原有极轻语义方向增量继续生效。
- 本轮文本清洗、数字日期朗读、专名保护、完整语义分块均未修改；`ә ғ қ ң ө ұ ү һ і` 保留。
- `Бірінші.` 至 `Он үшінші.` 的 320 ms SSML 编号停顿继续在同一请求内。B/C 第一处实测安静区仍为 360 / 350 ms；句子/段落 chunk 接缝仍为 280 / 420 ms，保留句尾 release。
- 已增加的 0.95× / 1.05× 选项继续保留。其他声线、页面和地球模块不改。

## 速度、验证与限制

42 chunk / 1008.165 秒真实 PCM 回放，交错三轮计时，DSP 中位数约 4.86 → 3.93 秒。本测量是本机离线 DSP，不包含 Edge 网络、浏览器设备差异或 MP3 编码；不能宣称线上合成加速。没有增加 Edge 请求数，轻量后处理未见明显耗时增加。

生产构建与 20 项检查通过，另有严格 TypeScript 检查：完整文本、13 个编号停顿、正常男声周期保护、半频证据门控、不同低频的实际衰减、中高频保留、无声辅音型噪声与低幅尾部、流式失败/取消处理，以及现有页面和地球包回归。三组真实音频另外检查长度、频段、峰值、响度、编号停顿与接缝。

Edge 原模型的声带不规则性、部分喉部共振、长句韵律和音节发声仍可能存在。轻量 EQ 能降低特定成分的重量，无法重建正常声带振动或保证消除所有喉音。继续保留 Дәулет 的声线也限制了可接受的处理强度。
