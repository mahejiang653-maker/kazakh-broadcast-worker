# V52 第一批：新闻分镜控制

仅接入当前 `news-globe-run-20260920-v52-r1.html`，继续使用原有十条 DATA LOCK、场景引擎和 Cesium Viewer。没有引入其他项目的依赖、地图数据或模型。

## 使用

- **重播本条**：停止自动播放，从当前新闻的国家总览重新播放。总览中重播会返回上一次选中的新闻；首次打开时从第一条开始。
- **暂停分镜**：停留期间立即暂停并保留剩余时间；正在移动的镜头先到达目的地；已经开始的攻击或航母效果先完成本轮。状态文字分别显示等待暂停、已暂停或播放完毕。
- **继续分镜**：继续消耗暂停前剩余的停留时间。再次点击等待暂停中的按钮可取消请求。
- **设置 / 导入 → 分镜时长设置**：镜头移动、国家、行政区、地点各自可设 0.25～4 倍时长，1 倍保持原有节奏，2 倍更慢；结束画面可额外停留 0～60 秒。
- 设置在当前浏览器单独保存，从下一条或重播时生效。恢复默认按钮不修改新闻内容。浏览器拒绝持久保存时，界面会说明仅本次生效。

原“播放 / 暂停”按钮仍控制十条自动播放。自动切条同时等待原有最短新闻展示时间、实际分镜完成和攻击效果清理；分镜暂停的时间不计入自动切条倒计时。

## 实现边界

- `public/news-globe-v52-director.js` 保存独立播放状态，每条新闻创建自己的导航序号、设置快照、可暂停等待与资源集合。
- 国家、地点与事件的语义检查点接在现有场景引擎；行政区通过原 `flashAdmin` 适配。地点特写完成后可停留；恢复时若横竖屏已变，攻击镜头先重新适配画布。
- 镜头倍率只改变时长参数；攻击弹道、三次命中、未知发射源规则、地理坐标、地图清晰度和国家边界范围沿用原有实现。
- 切新闻、重播、总览和页面销毁时解除等待。已排队的旧等待回调带独立代次校验；旧异步结果不能改变新播放状态。销毁也使旧导航序号失效。
- 导航和镜头取消继续返回失败，不因新增控制被当作成功。原图层的实际 GPU 几何就绪条件继续生效。
- 调试状态：`NG14.v52Director.getState()`。设置快照：`getSettings()`。不保存新闻内容或凭据。

验收包括国家/地点/效果结束三个暂停位置、普通新闻与行政区、剩余时间、重播、自动播放、快速切换、总览清理、真实时长变化、刷新后保存、恢复默认和设置面板可达性。行政区用内置中国省级几何构造单独的工程场景，不宣称为真实新闻。
